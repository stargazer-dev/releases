## What it does

You star things and never find them again. Stargazer reads every repo you have
starred and writes a one-line summary, a few tags, and the platforms it runs on,
so "that Rust CLI for diffing JSON" is one search away two years later.

Your library lives on your own disk and never touches our servers.

- **Analyze.** AI reads each repo and writes a one-line summary, a few specific
  tags, and the platforms it runs on.
- **Organize.** Projects, tags, and a note per repo. Bulk-edit dozens at once.
- **Clean up.** Find the dead ones: archived, deprecated, untouched for years.
  Each gets a keep or unstar call with the reason next to it.
- **Search.** Names, notes and tags filter as you type. Or describe the thing you
  half-remember and AI ranks the library against it.
- **Read.** Open the file tree and read any file with syntax highlighting,
  without cloning. Download a selection as a zip.
- **Ask AI.** Ask one repo or your whole library. Answers come from the README,
  the file tree and your own notes.
- **Releases.** Subscribe to repos and every new version lands in one feed, with
  an asset filter by platform.
- **Browse.** A real GitHub browser with tabs, history by day, and a star button
  on every page.
- **Find similar.** Open a repo and Stargazer ranks the rest of your library
  against it.
- **Trending and rankings.** The 100 most-starred repos across 34 languages, for
  any date back to 2018, plus what is climbing fastest right now.
- **Backups.** Save a dated source snapshot of any repo into your sync folder.
- **Sync and export.** Your library syncs across your own machines through a
  folder you choose. Export and import as JSON whenever you want.

Stargazer is a Mac app today. Windows and Linux builds are coming, and a license
covers them when they land.

## Install

1. Download the `.dmg` above.
2. Drag Stargazer to Applications.
3. Open it and sign in with GitHub.

Today's build needs a Mac, Apple silicon or Intel.

---

## Updates

Stargazer updates itself. It checks this repository on launch and offers the new
version when there is one, so you never need to come back here.

If you would rather update by hand, download the latest `.dmg` and replace the
app.

---

## Bring your own AI

Every AI feature is off until you turn it on. We do not run an AI service, and
no prompt ever reaches us.

Point it at any OpenAI-compatible API with your own key. It ships with presets
for OpenAI, OpenRouter, Google AI Studio, Groq, Cerebras, DeepSeek, Alibaba Qwen,
Together, Mistral, xAI Grok, and OpenCode Zen and Go. Or run a model locally with
Ollama or LM Studio, and nothing leaves your machine at all.

## Privacy

Stargazer has no analytics, telemetry, ad networks or third-party trackers.

Your stars, tags, projects and notes stay on your own machine. The only thing we
store is your GitHub account id and username, which is how we match a license to
you. Your GitHub token lives in the system keychain and never reaches our servers.

Full policy: [stargazer.dev/privacy](https://stargazer.dev/privacy).
